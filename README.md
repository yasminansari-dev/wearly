wearly -- Project

Create a premium luxury fashion hero section for a clothing resale platform called Wearly.

Style

- Cinematic 3D showroom
- Dark midnight blue background (#071426) with subtle volumetric spotlight
- Premium, minimal, futuristic fashion aesthetic
- Apple × BOSS × high-end ecommerce feel
- Fullscreen (100vh), responsive desktop and mobile

Layout

- Left side (35%): content
- Center (40%): large floating 3D bomber jacket
- Left & right edges: partially visible previous/next clothing items in 3D
- Top center: Wearly logo
- Bottom center: minimal diamond slider indicators
- Bottom: glossy reflective floor with soft animated reflection

3D Animation (automatic only)

- No hover effects
- No mouse parallax
- Jacket slowly rotates 360° continuously
- Jacket gently floats up and down
- Side garments move on slow looping paths behind the center product
- Tiny floating dust particles in the background
- Soft breathing spotlight intensity every few seconds
- Seamless infinite animation loop

Typography

Headline:
REWEAR THE FUTURE

Description:
“Discover premium pre-loved fashion, donate quality clothing, and give every garment a second life.”

Buttons:

- Explore Collection (primary)
- Donate Clothing (glass secondary)

Colors

- Background: #071426
- Accent olive green: #3D4A2F
- Accent rose brown: #7C5A5B
- Text: Off-white (#F5F5F2)
- Glass borders: rgba(255,255,255,0.08)

Technical

- React.js + Vite
- Tailwind CSS v4
- React Three Fiber + Drei
- GSAP for automatic timeline animation
- Everything inside a single Hero.jsx component except GLB assets
- Smooth 60 FPS, realistic lighting and shadows
